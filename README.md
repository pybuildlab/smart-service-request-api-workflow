# 🚀 Smart Service Request & API Workflow System

🌐 **Live Demo:** https://smart-service-request-api-workflow.onrender.com/app

🔗 **GitHub:** https://github.com/pybuildlab/smart-service-request-api-workflow

📌 **Overview**

A lightweight service-request management system for managing internal service requests through a REST API and dynamic dashboard.

✨ **Features**

- 📊 Dashboard with live service-request information
- 📝 Create and manage service requests
- 🔄 Track request status
- ✅ Request validation and error handling
- 📚 REST API with documentation
- 🧪 Automated testing
- 🗄️ SQLite database
- 📱 Responsive modern UI

🛠️ **Tech Stack**

- Python
- FastAPI
- SQLite
- HTML / CSS
- JavaScript
- Uvicorn
- Pytest
- Render

🌐 **Deployment**

Deployed as a public FastAPI web application using Render.

📦 **Project**

Built as a portfolio project to demonstrate Python backend development, REST API design, database integration, automated testing, and responsive UI development.
